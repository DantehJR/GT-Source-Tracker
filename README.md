# GT-Source-Tracker
This repository contains decompiled source code from **Gorilla Tag** for developer reference and analysis.
The references are automatically updated with every update.

## Why?
- To provide an easier way for developers and modders alike to browse the games code.
- Make it easier to track updates over time.
- Easily view changes between each update.
